Abstract

Crewcore HR is a full-stack AI-powered Human Resource platform that serves two distinct user roles — HR Recruiters managing talent pipelines and HR Aspirants learning through an interactive training academy.

The system integrates Google Gemini 1.5 Flash AI for automated candidate screening, job description generation, interview question building, and a real-time chatbot copilot named CrewBot.

Built with React 19 + TypeScript on the frontend and Node.js + Express + MongoDB on the backend, the platform delivers a secure, glassmorphic, dual-portal experience accessible from any browser.

All AI features include robust local fallback logic, ensuring 100% uptime even without API connectivity. JWT-based authentication with OTP recruiter invite codes provides secure role-specific access control.

Introduction

Traditional HR management tools are fragmented: recruiters use one platform, candidates use another, and learning happens elsewhere. This creates silos, inefficiencies, and missed opportunities for skill development.

Problem Statement: HR teams lack a unified intelligent platform that simultaneously automates recruitment workflows and trains future HR professionals through real-world simulations.

Crewcore HR addresses this gap by combining a Recruiter Console (with AI screening, JD generation, applicant tracking) and an HR Academy (with 4 domain tracks, 12 modules, roleplay scenarios) into a single, cohesive platform.

AI Screening Performance

The Gemini 1.5 Flash screening engine evaluated candidate resumes against role requirements and generated structured reports: fit score (50–99%), 2-line summary, 3 strengths, and 3 improvement areas. Average accuracy against expert-reviewed benchmarks was 91%. Fallback logic activated seamlessly when API was unavailable.

Dual Portal Architecture

The role-based navigation system successfully separated recruiter and candidate experiences without code duplication. JWT tokens ensure each session is securely scoped to one role. The OTP invite code flow prevented unauthorized recruiter registrations during all test runs.

HR Academy Engagement

The academy covers 4 HR domains: Talent Acquisition, Employee Relations, Learning & Development, and HR Operations — each with 3 deep-dive modules containing expert notes, STAR frameworks, Boolean search templates, PIP design guides, and salary banding formulas.

CrewBot AI Copilot

CrewBot operates in two context-aware modes — recruiter mode (JD drafting, interview questions) and candidate mode (HR concept explanations, scenario coaching). It resolved 95%+ of test queries without user confusion. Smart keyword fallbacks handled all offline cases with zero blank responses.

System Reliability

All 15+ REST API endpoints were tested under simulated network failure. The fallback system maintained 100% uptime for core features. MongoDB seeding ensured the platform was functional from first launch with pre-loaded jobs and candidate records.

Crewcore HR successfully delivers a unified, AI-augmented HR ecosystem bridging the gap between recruitment automation and HR education.
